GBPS34-Emu

Emulador modular de código aberto em C++.

Objetivo inicial

Desenvolver uma base de emulação do Game Boy original (DMG).

Estado atual

- Estrutura inicial do projeto
- Memória de 64 KB em desenvolvimento
- Próximo passo: implementar o processador LR35902

Plataforma

Desenvolvimento inicial em C++17, com objetivo futuro de suporte Android.
